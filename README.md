## Projetos em destaque

**[sistema-bancario-api](https://github.com/diegoomarcelo/sistema-bancario-api)** — API REST bancária em Java + Spring Boot, com modelagem de entidades via JPA/Hibernate, persistência em MySQL e regras de negócio (depósito, saque, validação de saldo) protegidas com `@Transactional`.

**[Cafofo dos Peludos](https://github.com/diegoomarcelo/Cafofo_dos_peludos)** — Aplicação web full stack para gerenciamento de adoções de animais, com área administrativa protegida por login, CRUDs completos e testes automatizados com Jest, Cypress e Supertest.

**[Gestão de Pedidos](https://github.com/diegoomarcelo/gestao_de_pedidos)** — Sistema de e-commerce com validação rigorosa de regras de negócio (carrinho, cupons, frete) e cobertura de testes unitários com Jest.

**[Sistema de Cadastro de Alunos](https://github.com/diegoomarcelo/Sistema_De_Cadastro)** — Sistema de cadastro em Java, aplicando POO e arquitetura MVC com padrão DAO para persistência em MySQL.

**[Automação de Cadastro](https://github.com/diegoomarcelo/automacaodecadastro)** — Script de RPA em Python que automatiza o cadastro em lote de produtos num sistema web: login automatizado, leitura de base de dados via Pandas e preenchimento de formulários com PyAutoGUI.
